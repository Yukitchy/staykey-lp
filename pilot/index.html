01

なぜ、この1件が重要なのか

ただの「初めてのお客様」として扱うと、もったいない案件です。理由を説明します。

この実験の本当のテーマ

「導入は、ぜんぶおまかせ」は、遠隔でも成立するのか？

ソイさんは東京（住吉）、かすみさんは熊本。現地に行けません。
StayKeyの一番の売り＝「むずかしい設定は全部こちらで」を、距離を越えて届けられるかがここで判明します。

✅ 成立したら

商圏が全国になります。ラジオ（全国のリスナー）が本物の販路になり、移動コストゼロで売れる商品になる。

⚠️ 成立しなかったら

商圏は東京近郊に限定。単価を上げて出張費を乗せる設計へ切り替える必要があります。
早く分かるほど傷が浅い。

💡 提案：哲郎さん（東京・近距離）と同時に走らせると、近い／遠いの差が数字で出ます。導入にかかる時間の差＝そのまま出張費の根拠になり、価格設計が一気に固まります。

03

段取り（5フェーズ）

各フェーズに「ここで何が分かればOKか」を置いてあります。ダメなら早く降りるのも成功です。

PHASE 0

ソイさんと目的を合わせる

今日〜明日
  • この1件の目的は「売ること」でなく「遠隔導入の可否を確かめること」だと合意する
  • 無料／有料の線引きを決める（→ 03章）
  • 約束すること・しないことを決める（→ 04章）
  • 撤退ラインを先に決める（→ 05章）
🎯 ここでの合格：ソイさんが「これはテストで、失敗してもいい」と理解している
PHASE 1

かすみさんヒアリング（オンライン30分）

今週

聞くこと。太字は導入可否に直結する必須項目です。

  • 物件の種類（民泊／レンタルスペース／間貸し／その他）と部屋数
  • 今の鍵の運用（物理キー手渡し／キーボックス／すでにスマートロック）
  • 一番の困りごと（深夜対応？ 遠方で行けない？ 清掃業者の出入り？）
  • 使っている予約サイト（Airbnb／スペースマーケット／その他）
  • ドアと鍵の形 ← セサミが付くかはここ次第。写真をもらう
  • ドア付近にWi-Fiが届くか ← ハブに必須。届かないと成立しない
  • 現地で手を動かせる人がいるか（本人／家族／清掃スタッフ／管理会社）
  • ゲストの層（国内／海外・スマホ操作の得意不得意）
🎯 ここでの合格：ドア写真とWi-Fi状況が手に入り、設置できる人が特定できている
PHASE 2

適合チェック（写真判定）

1〜2日
  • ドア内側・サムターン周辺の写真をソイさんが見て「付くか」を判定
  • 付かない錠前ならここで正直に伝えて撤退。お互いの時間を守る
  • 付く場合は必要な機器と数量を確定（セサミ＋ハブ3／1ハブで5台まで）
🎯 ここでの合格：「付く／付かない」が写真だけで判定できた（＝営業も遠隔でできる証明）
⚠️ ここが遠隔ビジネスの最初の関門。写真だけで判定できないなら、その"判定の難しさ"自体が重要な発見です。
PHASE 3

機器を送る → ビデオ通話で一緒に設置

1週間
  • セサミ＋ハブを熊本へ発送（費用は03章の方針で）
  • 設置日を決め、ビデオ通話でドアを映してもらいながら一緒に取り付け
  • 予約サイト連携はソイさんが遠隔で設定
  • 所要時間をストップウォッチで計測（＝導入代行の原価そのもの）
  • つまずいた箇所を全部メモ（＝AIサポートFAQの素材）
🎯 ここでの合格：2時間以内に解錠テストまで通る。超えるなら商品設計の見直しが必要
PHASE 4

実運用（2週間〜1ヶ月）

1ヶ月
  • 実際のゲストで運用してもらう
  • 質問・トラブルをすべて記録（件数と内容が保守費の根拠になる）
  • 「元の鍵運用にすぐ戻せる手順」を渡しておく（安心材料＆事故対策）
  • 2週目に一度こちらから様子を聞く（放置しない）
🎯 ここでの合格：締め出しゼロ。質問が出ても自己解決 or 短時間で解消できている
PHASE 5

振り返り・事例化

1ヶ月後
  • 感想をもらう → LPの「お客様の声」1件目（今はサンプル表示のまま）
  • 写真・許可をもらって導入事例に
  • 「いくらなら払うか」を本人に聞く ← 一番リアルな価格データ
  • ラジオでゲストとして話してもらう案も（＝そのまま次の営業になる）
🎯 ここでの合格：価格の実データと、次の人に見せられる事例が1件できている

05

約束すること／しないこと

ここを曖昧にすると、あとで必ずこじれます。最初に口頭でも文面でも伝えておく。

✅ 約束する

  • 設置から使えるようになるまで最後まで伴走する
  • 合わなければ元の鍵運用に戻せる（撤去も手伝う）
  • 事例として出す時は必ず事前に確認する
  • 困った時の連絡先を明示する

⚠️ 約束しない（先に伝える）

  • 完成品ではなくテスト版であること
  • 24時間365日の即対応はまだできない（体制構築中）
  • 不具合が起きる可能性がある前提で使ってもらう
  • 予約サイトの仕様変更で止まる場合がある
⚠️ 特に「締め出し（解錠できずゲストが入れない）」が起きた時の連絡手順と代替手段は、導入前に必ず決めて渡しておくこと。ここだけは事故ると信頼が一発で消えます。

07

撤退ライン（先に決めておく）

「やめどき」を最初に決めておくと、情に引きずられず冷静に判断できます。

🚪 ドアに付かない

Phase 2で正直に伝えて終了。傷は浅い。錠前の型番リストを作る材料にする。

⏱ 設置が2時間を超える

遠隔導入がビジネスとして割に合わない兆候。手順書・動画マニュアルの整備が先と判断する。

🔒 締め出しが起きた

即座に物理キー運用へ戻す。原因が特定できるまで次の顧客には売らない。
